# Target-Capture Scaling (TCS) v4.0

Analysis code, data workbooks, and machine-verified proofs accompanying the manuscript **"Scale degeneracy: the physical basis of calibration and absolute quantitation in molecular binding"** (preprint: ChemRxiv, DOI: [10.26434/chemrxiv-2024-19rj6](https://chemrxiv.org/doi/full/10.26434/chemrxiv-2024-19rj6/v10)).

The TCS framework derives the exact equation of state for equilibrium finite-site binding from the canonical partition function, reducing every binding-based assay to two dimensionless quantities: the normalized target feed (xi) and the binding-regime parameter (kappa). All platforms, from the 1960 radioimmunoassay to digital PCR and single-molecule arrays, appear as kappa-regime limits of this single equation.

## Repository layout

- `Code/TCS_scripts_EN/TCS_scripts_EN_1/` — 24 self-contained Python scripts reproducing all quantitative results. Every main-text, Extended Data and Supporting Information figure (Figs. 1c, 1d, 2a, 2b; Extended Data Figs. 1–5; SI figures in S1c, S2b, S9, S10) is regenerated by its named script. The Supporting Information tables are produced by the corresponding scripts as formatted console output. The remaining scripts are console-only verifications of numerical values quoted in the text — including the 4PL/5PL concentration-error ranges reported in main-text Table 1 (`SI_S3_4pl_5pl_verification.py`). Several scripts additionally write machine-readable CSV summaries. Script filenames follow the scheme `<scope>_<anchor>_<topic>.py` with scope prefixes `SI_` (SI sections/figures/tables), `Main_` (main-text figures), `ED_` (Extended Data figures) and `SD_` (Supplementary Data workbooks).
- `Supplementary_Data_1–5.xlsx` — analysis workbooks for the five datasets: multi-capacity immunofluorescence global fit (SD1); digitised Yalow & Berson (1960) RIA (SD2); Simoa sβG benchmark (SD3, Rissin et al., 2010); Simoa IL-6 training data and the 34-specimen clinical test set benchmarked against the Roche Cobas ECLIA reference assay (SD4); and dPCR partition data from two foundational studies (SD5). Each workbook contains the raw data, fitted parameter values, bootstrap/MCMC samples and convergence diagnostics.
- `lean_tcs/` — Lean 4 formalisation of the theory. All 76 numbered mathematical statements in the manuscript and Supplementary Information compile with no unproven steps (`no sorry`); see `lean_tcs/VERIFICATION.md` for the statement-by-statement mapping and `lean_tcs/build.log` for the build record.

## Data collection

Immunofluorescence and Simoa IL-6 measurements were performed in the authors' laboratories; the 34 clinical specimens were de-identified residual samples. The RIA, sβG and dPCR datasets were digitised or reanalysed from the cited original publications.

## Software requirements

Python 3.13 (tested with Python 3.13.9, Anaconda distribution) with standard scientific packages (NumPy, SciPy, pandas, Matplotlib); no proprietary or non-standard dependencies. Each script runs standalone and writes its figure and console output directly. The Lean 4 project builds with the current stable Lean toolchain (`lake build` in `lean_tcs/`).

## Code Ocean capsule

The Python code directory is Code Ocean ready: `Code/TCS_scripts_EN/TCS_scripts_EN_1/` contains a `requirements.txt` pinning all third-party packages, an executable `run` script that executes every analysis script in sequence and collects all generated figures, workbooks and CSV summaries into `../results`, and a `README.md` mapping each script to the figure, table or in-text numerical result it reproduces.
